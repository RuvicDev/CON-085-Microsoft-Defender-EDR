¿Qué es y para qué sirve?

El conector Microsoft Defender for Endpoint permite que el agente de Ruvic consulte alertas y dispositivos protegidos, aísle o libere equipos comprometidos y revise sus vulnerabilidades. Puedes pedirle cosas como:

  • "¿Qué alertas de severidad alta siguen nuevas en Defender?"
  • "Aísla el equipo laptop-ventas-07, tiene ransomware (ticket INC-123)."
  • "¿Qué vulnerabilidades críticas tiene el servidor srv-app01?"

Operaciones soportadas:

OperaciónQué hace
alerts.listConsulta alertas por severidad y estado
devices.listLista dispositivos con estado de salud y riesgo
device.isolateAísla un equipo de la red (Selective o Full)
device.releaseLibera un equipo aislado
vulnerabilities.listObtiene CVE de un equipo o de la organización
Aislar un equipo corta su red de inmediato El aislamiento es una acción real sobre el equipo. El agente solo la ejecuta cuando se lo pides y siempre registra el motivo.

Prerrequisitos

  • Licencia de Microsoft Defender for Endpoint (Plan 2 o Microsoft 365 E5) con equipos incorporados.
  • Rol de Administrador de aplicaciones o Administrador global en Microsoft Entra ID para registrar la aplicación y dar consentimiento.

Configuración en el fabricante

Vas a registrar una aplicación en Microsoft Entra ID con permisos de la API de Defender.

  1. Registra la aplicación.

    En Microsoft Entra ID → Registros de aplicaciones → Nuevo registro, crea "Ruvic Defender" para una sola organización. Copia el Id. de aplicación (cliente) y el Id. de directorio (inquilino).

  2. Agrega los permisos.

    En Permisos de API → Agregar un permiso → API que usa mi organización → WindowsDefenderATP → Permisos de aplicación, marca Alert.Read.All, Machine.Read.All, Machine.Isolate y Vulnerability.Read.All.

    [ Captura: permisos de WindowsDefenderATP en la aplicación — reemplazar por assets/img/defender-permisos.png ]
  3. Concede el consentimiento.

    Pulsa Conceder consentimiento de administrador y verifica que todos los permisos queden en verde.

  4. Crea el secreto.

    En Certificados y secretos → Nuevo secreto de cliente, copia el Valor de inmediato.

Permisos requeridos

Permisos de aplicación de la API WindowsDefenderATP. Omite Machine.Isolate si quieres un conector solo de lectura.

PermisoPara qué lo usa el conector
Alert.Read.AllConsultar alertas
Machine.Read.AllListar dispositivos
Machine.IsolateAislar y liberar equipos
Vulnerability.Read.AllConsultar vulnerabilidades

Configuración en Ruvic

Entra a Settings → Conectores, busca la tarjeta Microsoft Defender for Endpoint (EDR) y pulsa Configurar. Diligencia el formulario con los valores de la sección anterior:

Campo del formularioValor
Tenant ID (Directory ID)Id. de directorio (inquilino) de Microsoft Entra ID
Client ID (Application ID)Id. de aplicación (cliente) de la aplicación registrada
Client SecretEl Valor del secreto (no el Id. de secreto). Se guarda cifrado
URL base de la APIDéjalo por defecto o usa un endpoint regional
Timeout de conexión (segundos)Opcional; 30 segundos por defecto

Guarda y pulsa Probar conexión: la plataforma valida las credenciales y el acceso.

[ Captura: formulario del conector Microsoft Defender for Endpoint (EDR) en Settings → Conectores — reemplazar por assets/img/defender_edr-form.png ]

Verificación

  1. Test de conexión exitoso.

    El botón Probar conexión debe responder con éxito y la tarjeta debe quedar en estado Configurado.

  2. Prueba mínima con el agente.

    Abre una conversación nueva y pídele:

    "¿Cuántas alertas nuevas hay en Defender y en qué equipos?"

    El agente debe responder con alertas reales. No le pidas aislar equipos durante la prueba.

Solución de problemas

Mensaje / síntomaCausa probable y solución
"No se pudo obtener el token … AADSTS7000215"El secreto es incorrecto o venció. Crea uno nuevo y copia el Valor.
"Permiso insuficiente" (403)Falta un permiso de WindowsDefenderATP o el consentimiento de administrador.
"device_id debe ser el ID de máquina…"Se pasó el nombre del equipo. Obtén el ID con list_devices.
"Límite de peticiones" (429)Se superaron 100 llamadas por minuto. Espera un minuto.

Preguntas frecuentes y notas de seguridad

¿Qué diferencia hay entre aislamiento Selective y Full?

Selective mantiene Outlook, Teams y Skype para comunicarse con el usuario; Full corta todo excepto Defender.

¿Puedo dejar el conector solo de lectura?

Sí: no concedas Machine.Isolate. El aislamiento fallará con un error de permisos.

¿Qué hago si el secreto se filtra?

Elimínalo en Certificados y secretos, crea uno nuevo y actualízalo en el formulario.
